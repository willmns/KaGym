# KaGym

App de treino (musculação A/B/C + Pilates) para celular. Arquivo único, funciona offline.

## Fotos dos aparelhos

Todos os aparelhos já usam fotos de catálogo ligadas por link (o objeto `FOTOS` no `index.html`). Os links podem sair do ar; nesse caso o app tenta a pasta `fotos/` e, por fim, mostra o botão "Minha foto".

Coloque as fotos na pasta `fotos/`, em JPG, com estes nomes. O app mostra a foto automaticamente.
Se faltar o arquivo, aparece o botão "Minha foto" para tirar uma pelo celular.
