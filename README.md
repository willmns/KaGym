# KaGym

App de treino (musculação A/B/C + Pilates) para celular. Arquivo único, funciona offline.

## Treino

Fase 1: adaptação (4 semanas). Treinos A (pernas), B (superior) e C (posterior e glúteos), com caminhada leve nos outros dias.

## Fotos dos aparelhos

Todos os aparelhos usam fotos de catálogo ligadas por link (o objeto `FOTOS` no `index.html`). Os links podem sair do ar; nesse caso o app tenta a pasta `fotos/` (arquivo `<chave>.jpg`) e, por fim, mostra o botão "Minha foto".
